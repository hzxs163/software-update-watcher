源的选择器规则已内置，无需配置。新增源：把「站名 + 列表页地址」告知豆包， 或直接在仓库 src/config.json 的 sources 加一条。

导出后覆盖仓库 src/config.json 并提交即生效；密钥建议配 GitHub Secrets： WXPUSHER_APP_TOKEN、WXPUSHER_UID。每 6 小时自动检查（可手动触发）。
