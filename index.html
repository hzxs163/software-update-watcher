软件更新监控 · 配置台

首页设置关注关键词，命中关键词的新更新才会推送；源规则已内置，后续陆续添加即可

① 关注关键词（全局）

每行一个或用逗号分隔；列表页出现标题含任一关键词的新条目时才推送。

② 监控中的软件站源 0

源的选择器规则已内置写死，无需配置。后续新增软件站，把「站名 + 列表页地址」告知豆包， 或直接在仓库 src/config.json 的 sources 里加一条即可。

③ 定时与推送

定时任务在仓库 Actions 中每 6 小时自动运行（可手动触发）。
把导出的 config.json 覆盖仓库 src/config.json 并提交即可生效； 推送密钥建议配置为 GitHub Secrets：WXPUSHER_APP_TOKEN、WXPUSHER_UID。

使用步骤

  1. 在本页顶部设置「关注关键词」，点保存。
  2. 点击「导出 config.json」，把内容保存为仓库中的 src/config.json。
  3. 在 GitHub 仓库 Settings → Secrets and variables → Actions 添加密钥： WXPUSHER_APP_TOKEN（应用令牌）、WXPUSHER_UID（你的 UID）。
  4. Actions 每 6 小时自动抓取；首次运行只建立基线不推送，之后命中关键词的新条目才推送微信。
  5. 也可到 Actions 页面手动触发「check-updates」立即检查。

源怎么加

  1. 当前已内置「小刀娱乐网-绿色软件」等源，解析规则已写死。
  2. 新增源：在 src/config.json 的 sources 数组加一条 {id, name, list_url, item_selector, title_selector, date_selector, max_items, enabled}。
  3. 不同网站结构不同，选择器需按其页面调整；不确定时直接告知豆包帮你配置。
  4. 关键词是全局的：所有源统一按同一组关键词过滤。

WxPusher 注册

  1. 打开 https://wxpusher.zjiecode.com 注册账号。
  2. 创建应用，得到 App Token（AT_ 开头）。
  3. 用微信扫码关注应用，在「用户管理」复制自己的 UID。
