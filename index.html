定时与推送

定时任务在仓库 Actions 中每 6 小时自动运行（可手动触发）。
把导出的 config.json 覆盖仓库 src/config.json 并提交即可生效； 推送密钥建议配置为 GitHub Secrets：WXPUSHER_APP_TOKEN、WXPUSHER_UID。

使用步骤

  1. 在本页添加/编辑要监控的软件站源，配置推送。
  2. 点击「导出 config.json」，把内容保存为仓库中的 src/config.json。
  3. 在 GitHub 仓库 Settings → Secrets and variables → Actions 添加密钥： WXPUSHER_APP_TOKEN（应用令牌）、WXPUSHER_UID（你的 UID）。
  4. Actions 每 6 小时自动抓取；首次运行只建立基线不推送，之后有更新才推送微信。
  5. 也可到 Actions 页面手动触发「check-updates」立即检查。

添加新源的规则

  1. 列表页 URL：软件站按时间倒序的列表地址。
  2. 条目选择器：每条内容的外层容器，如 ul.list-soft li。
  3. 标题选择器：条目内标题链接，如 a.soft-title（取文本+链接）。
  4. 日期选择器（可选）：如 div.list-ca，配合「日期前缀」去掉“时间：”。
  5. 不确定选择器时，用浏览器 F12 查看元素后填写。
内置模板「小刀娱乐网-绿色软件」已配好，点「添加源」选择即可。

WxPusher 注册

  1. 打开 https://wxpusher.zjiecode.com 注册账号。
  2. 创建应用，得到 App Token（AT_ 开头）。
  3. 用微信扫码关注应用，在「用户管理」复制自己的 UID。
